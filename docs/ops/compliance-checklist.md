# 生成ポリシー & レビューガイド

| カテゴリ     | チェック項目                                         | 対応方法                                                                       | 備考                                   |
| ------------ | ---------------------------------------------------- | ------------------------------------------------------------------------------ | -------------------------------------- |
| 権利         | 実在人物を素材として使用していないか                 | アップロード画面で「生成物以外は禁止」を明示。違反時はストレージ保存せず破棄。 | MVPではカットモデルは必ずAI生成。      |
| 参照画像     | 利用権限区分が選択されているか                       | `社内撮影 / 有償素材 / 生成AI` から選択し、メタ情報に保存。                    | 有償素材はライセンスIDを必須入力。     |
| ムード整合性 | 選択したムードプリセットと著しく乖離していないか     | 生成メタ情報（プリセットID・キーワード）を表示し、レビュー時に比較。           | 将来的に画像解析で自動判定予定。       |
| 顔匿名化     | 匿名化レベル（keep / soft / distinct）が要件に沿うか | ギャラリーに匿名化レベルを表示し、承認者が目視確認。                           | 公開時は "AI generated" 表記を必須化。 |
| 品質         | 画質・照明・アーティファクトの有無                   | ノイズ、歪み、指の形状等のチェックリストを用意。                               | 問題があれば再生成を推奨。             |
| 出力         | 用途別フォーマットが揃っているか                     | エクスポートで自動整形。命名規則とプレビュー確認を行う。                       | SNS/紙面など用途別テンプレを管理。     |

## 承認プロセス（MVP）

1. 生成直後：デザイナーがギャラリーで一次チェックし、NGの場合は即再生成。
2. お気に入り登録：担当者がムード整合性／匿名化レベル／ライセンス情報を確認し、カタログへ昇格。
3. 外部利用前：生成物である旨を追記したテンプレートを利用し、最終承認者が用途ごとの可否を判断。

## ムードプリセット運用ガイド

- **キーワード**：ムードを表す形容詞（例：ポップ、クール、透明感）を最大5語。プロンプトにそのまま挿入。
- **カラー**：主要な色味を3色以内で定義し、背景・衣装・照明に反映させる。
- **ターゲット像**：年代・ライフスタイルを文章で記載し、モデル生成時の説明文に使用。
- **背景シーン**：スタジオ／屋外など代表的な背景を設定し、必要に応じて上書き可能にする。

## 運用メモ

- 生成ログと採用結果を月次で振り返り、ムードプリセットの追加・調整に活用する。
- 参照画像は利用期限（例：90日）を設け、期限切れは自動削除する。
- SynthIDや生成メタデータを保持し、外部配布時にAI生成であることを明示できるようにする。
