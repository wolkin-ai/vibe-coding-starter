# 生成ポリシー & ブランドチェック

| カテゴリ | チェック項目                                                 | 対応方法                                                                             | 備考                                     |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------ | ---------------------------------------- |
| 権利     | 実在人物を素材として使用していないか                         | アップロード画面で「生成物以外を禁止」チェックを明示、違反時はストレージ保存せず破棄 | MVPではカットモデルは必ずシステム生成    |
| 参照画像 | 利用権限区分が選択されているか                               | `社内撮影 / 有償素材 / 生成AI` から選択、メタ情報に保存                              | 有償素材利用時はライセンスID入力必須     |
| ブランド | テイストプリセットに沿った色味・キーワードが設定されているか | 保存前にブランドテーマとの乖離スコアを表示（簡易ルール）                             | 将来は画像解析で自動判定を強化           |
| 顔匿名化 | 匿名化レベルが要件（keep/soft/distinct）に合致しているか     | ギャラリー表示時にメタ情報を表示し、承認者が確認                                     | Public配布時は“AI生成モデル”表記を必須   |
| 品質     | 画質・照明・アーティファクトの目視確認                       | ギャラリーでチェックリストを提供（ノイズ、歪み、指の形状など）                       | 必要に応じて再生成案内                   |
| 出力     | 用途別フォーマット（1:1, 4:5, 3:4）を揃えているか            | エクスポート時に自動リサイズ＋命名規則                                               | プレビューと実サイズを比較できるUIを用意 |

## 承認プロセス（MVP）

1. 生成直後：デザイナーがギャラリーで一次チェック、問題があれば即再生成。
2. お気に入り登録：ブランド責任者がブランド整合性を確認し、カタログに追加。
3. 外部利用前：生成である旨・ブランド表記を差し込んだテンプレを活用し、社内ガイドラインに沿って共有。

## ブランドテーマ設定ガイド

- **カラー**：ブランドの主要カラーをHEXで最大3色。プロンプト内で衣装・背景・ライティングに反映。
- **キーワード**：スタイル形容詞（例：グロッシー、ストリート、透明感）を最大5語。
- **ターゲット**：年代・性別・ライフスタイルを文章で記載し、プロンプトのコンテキストに添える。
- **背景シーン**：スタジオ、路地裏、夜景など、ブランドらしい背景を1〜2パターン。

## 運用メモ

- 生成ログと採用結果を毎月レビューし、ブランドテーマやレシピの改善に繋げる。
- 参照画像は削除期限（例：90日）を設定し、使い回し時にはライセンス再確認を行う。
- SynthIDなどのメタ情報は削除しない。外部配布時は「AI生成」であることを明記する文章をテンプレ化する。
