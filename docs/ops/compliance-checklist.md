# 生成スタイルレビューガイド（β版）

| カテゴリ       | 項目                                                 | 判定方法                        | 備考                                    |
| -------------- | ---------------------------------------------------- | ------------------------------- | --------------------------------------- |
| リアリティ     | 肌・髪の質感が自然か                                 | 目視確認 + 不自然箇所にコメント | 過度な描写は却下推奨                    |
| スタイル整合性 | 指定したパラメータ（長さ/カラー/前髪など）を満たすか | 生成ログ（パラメータ）と比較    | ずれが大きければ再生成                  |
| 目線・表情     | 意図した表情か、目線が破綻していないか               | 目視確認                        | 顧客利用を想定し違和感がある場合は却下  |
| 背景           | 背景がノイズ・破綻なく、サロンブランドに合うか       | 目視確認                        | 不要物が多い場合は再生成                |
| 一貫性         | 同一プロジェクト内の他案とテイストが揃っているか     | 並列比較ビュー                  | セット提案ならカラー/質感の整合性を確認 |
| 安全性         | Google Gemini Safetyの警告が出ていないか             | レスポンス`saftyFlags`          | `disallowed`が含まれる場合は自動却下    |
| 共有適性       | 顧客に見せても誤解を招かないか                       | 担当者コメント                  | 加工内容を説明できるか確認              |

## 運用ルール

- 生成案は最低1名のレビュー担当が目視し、承認・却下・メモを残す。
- 承認した案は`approved`ステータスに遷移し、再生成する場合は新しいジョブを作成する。
- 再生成が3回以上続く場合はプロンプトテンプレやパラメータの見直しを行う。
- 不適切と判断した案は即座に削除し、`audit_logs`に理由を記録する。
