# AI生成ビジュアル利用ディスクレーマー（ドラフト）

## 目的

実在の人物素材を扱わず生成AIで作成したビジュアルを社外公開する際、権利・倫理面での説明責任を果たすための文面テンプレート。

## 表記テンプレート（SNS / Web）

```
本投稿で使用しているモデル画像は、当社がムードプリセット（例：ギャル／モード等）と生成AI（Google Gemini 2.5 Flash Image）を組み合わせて作成したビジュアルです。実在の人物ではありません。
```

- 必要に応じて「ヘアスタイルの再現には個人差があります」等の注意書きを追加。

## 社内資料テンプレート

```
・生成目的：ムード「○○」のカタログ検討用
・生成日時：2025年10月4日
・使用モデル：AI生成（ID: mdl_20251004_012）
・参照素材：ref_20250930_003（社内撮影）
・外部使用可否：検討中（最終承認待ち）
```

## 利用ポリシー

1. 生成物を公開・配布する際は、AI生成である旨を明記する。
2. 参照画像に外部素材を利用した場合、ライセンス条項と出典を添付する。
3. カウンセリング用途では仕上がりが実際と異なる可能性を説明する。
4. 不適切な表現（人種・性別ステレオタイプ等）は禁止。ムードプリセットは多様性を損なわないよう運用する。

## 承認フロー（参考）

1. デザイナーが生成 → ギャラリーに登録。
2. 担当者がムード整合性・匿名化レベル・ライセンス情報を確認し、お気に入り／カタログへ昇格。
3. マーケティング担当が投稿素材を最終チェックし、ディスクレーマーを挿入。
4. 公開後は使用実績を記録し、必要に応じて差し替え・削除対応を行う。
