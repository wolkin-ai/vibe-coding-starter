# AI生成ビジュアル利用ディスクレーマー（ドラフト）

## 目的

実在の人物素材を扱わず生成AIで作成したビジュアルを社外公開する際、権利・倫理面での説明責任を果たすための文面テンプレート。

## 表記テンプレート（SNS / Web）

```
本投稿で使用しているモデル画像は、当社がブランドコンセプトに基づき生成AI（Google Gemini 2.5 Flash Image）で作成したビジュアルです。実在の人物ではありません。
```

- 必要に応じて「ヘアスタイルの再現には個人差があります」等の注意書きを追加。

## 社内資料テンプレート

```
・生成目的：ブランド「○○」のカタログ検討用
・生成日時：2025年10月4日
・使用モデル：AI生成（ID: mdl_20251004_012）
・参照素材：ref_20250930_003（自社撮影）
・外部使用可否：検討中（要ブランド責任者承認）
```

## 利用ポリシー

1. 生成物を公開・配布する際は、AI生成である旨を明記する。
2. 参照画像に外部素材を利用した場合、ライセンス条項を添付する。
3. お客様にカウンセリング素材として提示する際は、仕上がりが実際と異なる可能性を説明する。
4. 不適切な先入観を与える表現（人種・性別ステレオタイプ等）は禁止。ブランドテーマは多様性に配慮する。

## 承認フロー（参考）

1. デザイナーが生成 → ギャラリーに登録
2. ブランド責任者が内容を確認し、外部使用可否を判断
3. マーケティング担当が投稿時にディスクレーマーを挿入
4. 公開後は使用実績を記録し、必要に応じて差し替え/削除対応を行う
