# 電子同意書テンプレート要素

## 必須項目

1. 被写体氏名（漢字・カナ）
2. 生年月日（未成年の場合は法定代理人情報）
3. 撮影日・撮影場所
4. 利用目的（サロン公式サイト、SNS、店内提案資料など）
5. 掲載期間と掲載終了後の扱い
6. 画像の加工方針（生成AIを含むスタイル提案である旨）
7. 二次利用範囲（販促物、店内掲示、顧客への比較共有など）
8. 撤回手続き（撤回受付窓口と反映期日）
9. 報酬または無償である旨
10. 個人情報の取り扱い（保管期間、管理責任者）
11. 同意者署名（手書きまたは電子署名）と署名日時

## 推奨文言（例）

```
本同意書にご署名いただくことで、当サロンが撮影した写真またはお客様から提供された写真を、生成AIによるスタイル提案の素材として利用することに同意したものとみなします。
生成AIで作成したスタイル案はカウンセリング・提案用途を主とし、実際の仕上がりには個人差が生じる可能性があることをご理解ください。
同意の撤回を希望される場合は、下記お問い合わせ先までご連絡ください。原則として○営業日以内に生成画像および関連データの利用を停止いたします。
```

## 証跡管理

- 署名済みPDFを`consents/`バケットに保存し、ファイル名に`<consentId>_<yyyymmdd>.pdf`を使用。
- 署名時点のIPアドレス・端末情報を`consent_events`テーブルに保存。
- 同意期限切れの30日前に自動通知を送る仕組みをPhase2で導入予定。

## 参考運用メモ

- 同意書は撮影または素材提供のたびに取得し、複数プロジェクトで利用する際は本人確認を再実施。
- 未成年モデルの場合は法定代理人の同意書を別添する。
- 口頭同意のみは不可。必ず電子署名または手書き署名をアップロードする。
