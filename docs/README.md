# docs ディレクトリガイド

このフォルダはプロダクト仕様と開発運用に関する一次情報を集約します。ドキュメント更新時は以下のルールを遵守してください。

- 各サブフォルダの責務に沿ってファイルを配置すること
  - `product/`: 目的・価値提案・スコープ
  - `tech/`: 技術アーキテクチャ・連携仕様
  - `ops/`: 運用手順・コンプライアンス・出力規約
- レビュアブルな粒度で加筆した場合はPRにドキュメント変更点を明記すること
- 仕様変更の発端（ユーザーフィードバックや法令対応など）は本文または脚注に追記すること
- 図版はMarkdown内にテキスト記述で残し、必要に応じて外部ツールのエクスポート先を記録すること

ドキュメントの更新履歴はGit履歴で管理し、最新情報を参照するようにしてください。
