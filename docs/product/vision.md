# プロダクトビジョン

## 目的

- 実在人物に依存せず、ブランドの世界観に合ったカットモデルとヘアカタログを高速に生成・管理する。
- サロンや制作チームが狙うペルソナ（ギャル、モード、韓国風など）を可視化し、ビジュアルでブランディングを確立する。
- 生成AIの品質と統一感を担保しつつ、社内利用で安全に反復検証できる運用基盤を提供する。

## 想定ユーザー

- **美容サロンのマーケティング/広報担当**：ブランドイメージに沿ったビジュアル素材を継続的に更新したい。
- **制作代行・デザインチーム**：複数ブランド向けのヘアカタログや広告素材を短納期で揃えたい。
- **新規開業サロン**：自店舗の世界観を定義し、開業初期から統一感あるビジュアルを構築したい。

## コア価値

1. **ブランド一貫性**：テイストプリセットとプロンプトレシピで生成結果の方向性を揃える。
2. **モデル資産化**：好みのカットモデルを生成・保存し、スタイル別に再利用できる。
3. **ヘアスタイル高速展開**：スタイルレシピとバッチ生成で、複数のヘアカタログ案を一度に比較・選定できる。

## 成果指標（KPI例）

- ブランドテーマごとの採用ビジュアル数と生成〜採用までのリードタイム
- 生成バッチあたりの採用率（お気に入り登録枚数／総生成枚数）
- ブランドテーマの閲覧数・活用率（カタログ利用回数、公募案件への採用数）
- 生成コストに対する採用ビジュアル単価の改善幅

## ロードマップ

- **Phase 1（MVP）**：ブランドテーマ設定、カットモデル生成、お気に入り保存、ヘアスタイル生成（指定モデル／モデル指定なし）、参照髪型適用。
- **Phase 2**：ブランドダッシュボード、ギャラリー比較、チームレビュー、コストモニタリング。
- **Phase 3**：マルチブランド管理、公開共有リンク、外部チャネル用フォーマット書き出し、自動レポート生成。
