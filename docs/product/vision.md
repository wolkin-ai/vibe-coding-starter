# プロダクトビジョン

## 目的

- アップロードした写真を起点に、希望スタイルのパラメータを調整して複数のリアルな仕上がり案を生成できるようにする。
- サロン現場でのカウンセリングや提案をスピードアップし、比較検討をしやすいUIで管理する。
- 生成結果のうち採用したものだけを承認・共有・エクスポートできるコンテンツ運用基盤を提供する。

## 想定ユーザー

- 個人美容師・1〜3席規模サロン：カウンセリング時に複数の完成イメージを即提示したい。
- 中〜大規模サロンの広報/店長：統一ブランドトーンを守りつつ、スタイリスト提案案を迅速に審査したい。
- 制作代行/代理店：店舗ごとの要望に応じたバリエーションを効率よく提示し、採用案を管理したい。

## コア価値

1. **スタイルバリエーション生成**：レングス/カラー/前髪/質感などのパラメータ操作で、複数案を短時間で生成。
2. **レビューと承認の一元管理**：生成結果を並べて比較し、承認/却下/メモを残せる。
3. **共有とエクスポートの効率化**：採用案だけを顧客向けPDF・SNS用出力などに素早く転用。

## 成果指標（KPI例）

- カウンセリング1件あたりの提案準備時間短縮率
- 提案案から採用案に至る承認率
- スタイリスト別の提案数および採用数
- 顧客満足度フィードバック（例：比較のしやすさ）

## 長期ロードマップ

- Phase 1：アップロード→パラメータ調整→複数生成→承認・エクスポートの最短フローをβ提供
- Phase 2：チームレビュー機能、コメント/比較ビュー、Slack通知などの協働強化
- Phase 3：顧客共有リンク、履歴比較、提案テンプレートや自動レポート出力の拡張
