# プロダクトビジョン

## 目的

- 実在人物に依存せず、サロンが狙うムード（ギャル／モード／ナチュラル等）に沿ったカットモデルとヘアスタイルを高速に生成・管理する。
- プリセットのムードヒントと手動パラメータの組み合わせで、ビジュアル方向性を素早く試行・蓄積できる基盤を整備する。
- 生成AIの品質と安全性を担保しつつ、サロン内で反復検証できるワークフローを提供する。

## 想定ユーザー

- **美容サロンのマーケ担当／スタイリスト**：旬のムードを押さえたカタログを短期間で制作したい。
- **制作代行・デザインチーム**：複数テイストを横断しながらヘアビジュアルを量産したい。
- **新規開業サロン**：まだ固まっていない世界観を、ムードプリセットを起点に試行錯誤したい。

## コア価値

1. **ムード一貫性**：システム提供のムードプリセット＋カスタム指示で方向性を素早く合わせられる。
2. **モデル資産化**：生成したカットモデルを保存し、ヘアスタイル生成で再利用できる。
3. **高速バリエーション**：スタイルパラメータとバッチ生成で、SNS／カタログ向け候補をまとめて比較できる。

## 成果指標（KPI例）

- ムード別の採用ビジュアル数と生成〜採用までのリードタイム。
- 生成バッチあたりの採用率（お気に入り登録枚数／総生成枚数）。
- カタログ画面でのタグ・ステータス操作による活用頻度（レビュー → 掲載への遷移）。
- 生成コストに対する採用品質（採用単価）の改善幅。

## ロードマップ

- **Phase 1（MVP）**：ムードプリセット提供、カットモデル生成、ヘアスタイル生成（モデル指定／バッチ／スタイル転写）、カタログ管理、書き出しテンプレート。
- **Phase 2**：ムードプリセットの編集、ギャラリー比較、チームレビュー、生成コストモニタリング。
- **Phase 3**：マルチワークスペース、共有リンク、外部チャネル向けレイアウト自動生成、レポートダッシュボード。
