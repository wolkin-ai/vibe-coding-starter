# Google Gemini 2.5 Flash Image 連携設計

## 役割

- ムードプリセットとヘアスタイルパラメータに基づいた高解像度のカットモデル・ヘアカタログ画像を生成する。
- モデル一貫性（同一人物での髪型変更）とスタイル転写（参照画像の髪型を適用）を実現する。
- 生成枚数とコストを制御し、SynthIDを含むメタデータを取得して保存する。

## 接続構成

```
Front (Next.js)
  ↓ REST
API Route /generate
  ↓ BullMQ
Worker (Node.js)
  ↓ HTTPS (Google API)
Gemini 2.5 Flash Image
  ↓
Storage (S3) + DB (Supabase)
```

## プロンプトビルド戦略

- **ステップ分割**：
  1. カットモデル生成（ムードヒント + 骨格/メイク/背景）
  2. ヘアスタイル生成 or 参照適用（既存モデル画像 + ヘアパラメータ or 参照画像）
- **テンプレ構成要素**：
  - ムードキーワード（ギャル／モード／フェミニン等）、カラーパレット、ライティング指示
  - モデル属性（年齢帯、顔型、表情、肌トーン）
  - ヘアパラメータ（長さ、ボリューム、前髪、質感、カラー処理）
  - 撮影設定（レンズ、背景シーン）
- プロンプトはJSONテンプレートで管理し、ムードプリセットごとに差し込む構造で実装する。

## 参照画像適用

- `generateContent` APIにベースモデル画像とヘア参照画像を複数`parts`として渡し、「ヘアスタイルを参考に同じ人物で再生成」と明示。
- 参照画像は髪の領域が明確なものを推奨し、必要に応じて事前に背景マスクを作成。
- 参照素材のライセンス情報（社内撮影／素材サイト／生成AI等）を`assets`テーブルへ記録する。

## バッチ生成

- バリエーションはアプリ側でループ生成し、温度・シードを少しずつずらす方式を採用。
- 1ジョブ最大10枚。まずは1024pxプレビューを生成し、採用候補のみ高解像度再生成する二段構えを提供。

## コスト見積り

- 画像出力は約 $0.039/枚（1024px） + 入力トークン課金。([ai.google.dev/pricing](https://ai.google.dev/pricing))
- ジョブ投入時に `batch_size × 単価` を計算し `generation_jobs.cost_estimate` に保存。完了後、レスポンスの使用トークンから実コストを再計算。
- 上限付近ではバッチサイズを自動調整し、ダッシュボードにアラートを表示する仕組みを検討。

## エラーハンドリング

- `429/503`：指数バックオフ＋最大3回リトライ。失敗時はジョブ`status = failed` に更新し、UIで再試行案内。
- Safety警告：`safetyRatings` をチェックし、ブロック理由をUIへ返す。必要に応じてムードや指示を調整する。
- 画像なしレスポンス：プレースホルダーを返しつつ、レスポンスのテキスト内容をログ保存。

## メタデータ管理

- 生成結果ごとに `response_id`、SynthID、プロンプトスナップショット、参照画像IDを保存。
- 外部利用時に「AI生成」であることを明示できるよう、SynthIDと履歴を保持。

## セキュリティ・運用

- APIキーはサーバー側のみで保持し、CI/CDではSecret Managerを利用。
- 生成画像は社内レビューを経てから外部公開する。ムードプリセットと乖離した場合は再生成ルールを設ける。
- 参照画像アップロード時に利用権限区分を選択させ、監査ログを残す。
